# Лента вакансий: cv.lv · cvmarket.lv · ss.lv

Каждый день в 07:17 по Риге бот собирает вакансии с трёх сайтов, отсеивает лишнее по `config.json` и обновляет страницу:
**https://natalialeaiart.github.io/vakances_lv/**

Почему не kurdarbs.lv: он отвечает «403 Forbidden» на любые запросы с серверов GitHub. kurdarbs сам собирает объявления с этих же сайтов, поэтому бот берёт их напрямую.

## Откуда берутся вакансии

| Источник | Как | Что даёт |
|---|---|---|
| cv.lv | вся база через открытый поиск сайта (~2000 вакансий) | название, компания, город, дата, удалёнка/гибрид |
| cvmarket.lv | поиск по словам `search` из `config.json` | название, компания, город, дата |
| ss.lv | разделы профессий `ss_sections` из `config.json` | текст объявления, компания, район, дата |

Если какой-то сайт не ответил, бот берёт вакансии с остальных и пишет об этом в логе. Данные не обновляются, только если не ответил ни один.

Вакансия уходит из ленты, когда ей больше 30 дней (`archive_days`) или когда её сняли с сайта. Снятые удаляются, только если бот в этот запуск просмотрел сайт целиком и без ошибок. Если сайт не ответил или вернул меньше половины обычного числа объявлений, с него в этот день ничего не удаляется.

## Что где лежит

| Файл | Зачем |
|---|---|
| `config.json` | ключевые слова, исключения, города, источники. **Единственный файл, который нужно править** |
| `scraper.py` | сам бот |
| `index.html` | страница-лента |
| `data/jobs.json` | найденные вакансии (бот обновляет его сам) |
| `.github/workflows/daily.yml` | расписание |

## Запустить вручную

**Actions** → «Вакансии — ежедневное обновление» → **Run workflow** → **Run workflow**. Через 2–3 минуты бот закончит, ещё через ~1 минуту обновится страница. С телефона то же самое работает в приложении GitHub (вкладка Actions).

Если при запуске ошибка «Permission denied» при `git push`: **Settings → Actions → General → Workflow permissions → Read and write permissions** → Save, и запустить снова.

## Как поменять слова

Откройте `config.json` на GitHub → карандаш → правьте → Commit.
- `search` — что бот вводит в поиск cvmarket.lv (латышский и английский).
- `title` — по каким словам в **названии** вакансия попадает в группу. Русские слова тоже работают.
- `description` — слова, по которым вакансия берётся, даже если их нет в названии (помечается «по описанию»).
- `exclude_title` — если это есть в названии, вакансия отбрасывается.
- `archive_days` — сколько дней держать вакансию в ленте (сейчас 30).
- `ss_sections` — какие разделы профессий ss.lv смотреть. Адрес раздела берите из ссылки на https://www.ss.lv/lv/work/are-required/.
- `sources` — выключить источник: поставьте `false`.
- Слова до 4 букв ищутся только целиком (`AI` не найдётся внутри `maiņu`), длинные — как часть слова (`personāl` = personāla, personālvadība).

Изменения применяются со следующего запуска, в том числе к уже найденным вакансиям.
